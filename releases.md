# Release notes

Current version: **1.0.0**

- **1.0.0**, *Sept. 14, 2026*: Initial release. Includes:

- Javascript library for reading plain-text files with syntactic analyses, and constructing sentence-level syntax graphs. Identifies subgraphs for verbal expressions. Composes Mermaid graph diagrams of syntactic dependencies. Formatting and visualization options include colored highlighting of verbal units in texts and in Mermaid diagrams, and highlighting of related nodes on hover in text displays.
- Single-page web app for loading and visualizing syntax analyses, functions when opened from a local file without a server.

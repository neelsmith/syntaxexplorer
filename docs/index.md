# `syntaxexplorer`

## A web app

In the `apps` directory of the [`syntaxexplorer` repository](https://github.com/neelsmith/syntaxexplorer), you find a `syntaxexplorer` web app for loading and visualizing syntax analyses. No web server is required: to run the app in a web browser, just open `syntaxbrowser/index.html`.


## A javascript library

[The `syntaxexplorer` repository](https://github.com/neelsmith/syntaxexplorer) hosts a javascript library for reading plain-text files with syntactic analyses, and constructing sentence-level syntax graphs. The library supports a variety functions for analysis and visualization of syntactic analyses.

See [a quick start to using the `syntaxexplorer` library](./quick.html)
